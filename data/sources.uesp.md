## Conflicts / notes

- `Online:Tales_of_Tribute_Decks` and `Online:Tales_of_Tribute_Game_Board` returned **404**; used individual patron pages.
- Current UESP patron index was checked through 2026; no patron after Saint Alessia is listed.
- Main UESP “How to Play” is incomplete; rules synthesized from Beginner’s Guide, Lore:Tales of Tribute, patron pages, and secondary guides.
- Some UESP prose card counts disagree with tables (e.g. Mora “8 unique” vs 7 named rows summing to 20); **tables trusted**.
- Saint Alessia Action starter has a spurious numeric column on UESP; treated as no HP.
- **Saint Alessia copy conflict:** UESP lists Whitestrake Ascendant copies=2, which produces 21 cards after all upgrades. An independent in-game-oriented card dataset lists 1 and restores the documented 20-card deck; `copies: 1` is selected and the card is flagged `needsReview` with `sourceConflict`.
- Upgrade vs base: both listed; use `copies`, `copiesAfterUpgrade`, `replaces` for collection-aware Tavern construction.
- Created tokens: Writ of Coin, Bewilderment, The Chimera; alsoCreated flags on Summerset Sacking, Maormer Boarding Party, Alessia soldiers, Wisp totems.
- If `cards.clean.json` exists on this box, it is an **alternate** fan schema from another builder. Required deliverables use the UESP-structured schema (`deckId`, `effects[]`, etc.). Mirrors: `*.uesp.json`.
